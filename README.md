# BrkRaw

BrkRaw (v0.5.0b1) converts raw data from Bruker Paravision preclinical MRI scanners into
standardized, neuroimaging-ready datasets, with extensible rules/specs and plugin hooks.

- Documentation: [brkraw.github.io](https://brkraw.github.io/)
- Releases: [github.com/BrkRaw/brkraw/releases](https://github.com/BrkRaw/brkraw/releases)
- PyPI: [pypi.org/project/brkraw](https://pypi.org/project/brkraw/)
